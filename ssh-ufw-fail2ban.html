Lab - Ubuntu Server com SSH + UFW + Fail2ban

Projeto prático realizado em máquina virtual para fortalecer acesso remoto seguro e defesa básica do servidor.

← Voltar para o início

Objetivo

Configurar um Ubuntu Server com SSH seguro, firewall ativo e proteção contra tentativas de acesso indevido.

Ambiente

  • Host: Linux Mint
  • VirtualBox
  • Ubuntu Server 24.04
  • Rede NAT + Host-Only

O que foi feito

  • Teclado ajustado para Português do Brasil
  • Hostname alterado para servidor
  • Teste de conectividade interna e internet
  • SSH funcionando entre máquinas
  • Chave ED25519 criada
  • Login por chave pública configurado
  • Autenticação por senha desativada
  • UFW ativado liberando porta 22
  • Fail2ban instalado e monitorando SSH

Problemas resolvidos

  • WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED
  • Configuração sobrescrita por 50-cloud-init.conf
  • Tentativas inválidas de login analisadas

Comandos usados

ssh ubuntu@IP sudo systemctl status ssh sudo ufw enable sudo ufw status sudo apt install fail2ban -y sudo fail2ban-client status sshd

Resultado Final

Servidor acessível por chave SSH, firewall ativo e proteção básica contra brute force configurada.
